Backup e Restauração

Exporte suas tarefas, hábitos, notas e registros de humor em um arquivo .json, ou importe um backup salvo anteriormente.

⚠️ Importar substitui completamente os dados atuais deste navegador. Essa ação não pode ser desfeita — exporte um backup antes, se tiver dúvida.

Backup automático — escolha um arquivo uma vez e o Gênesis o mantém atualizado sozinho, sem pedir de novo.

Conectar Google Agenda

Insira o Client ID OAuth do Google Cloud para sincronizar suas tarefas com prazo direto no Google Agenda.

O Client ID fica salvo apenas no seu navegador. A conexão em si usa o login OAuth oficial do Google — o Gênesis nunca vê sua senha.

📊 Relatório Semanal

Configurar APIs

Insira sua Groq API Key para ativar as respostas de IA inteligentes e em tempo real do Gênesis. Gere uma chave gratuita em console.groq.com/keys.

Sua chave é salva localmente apenas no seu navegador e nunca é enviada para outros servidores que não sejam a própria API oficial da Groq.

Opcional: uma Anthropic API Key ativa o modelo forte (Claude) para conversa aberta e raciocínio pesado. Sem ela, tudo continua rodando na Groq.
